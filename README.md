# Mathematics-statistics-for-DastaScience

## 📌 Project Overview

This project demonstrates the application of mathematical and statistical concepts using Python for Data Science.

The project covers:
- Linear Algebra
- Probability Concepts
- Descriptive Statistics

The analysis is implemented using Python libraries such as NumPy, Pandas, SciPy, and Statistics.

## 🎯 Objectives

- Perform vector and matrix operations using NumPy.
- Apply probability concepts to sales and customer purchase data.
- Implement Bayes' theorem and probability distributions.
- Calculate descriptive statistical measures.
- Interpret the statistical characteristics of the dataset.

## 🛠️ Tools & Libraries

- Python
- NumPy
- Pandas
- SciPy
- Statistics
- Jupyter Notebook / Google Colab

## 📊 Project Tasks

### 1. Linear Algebra

The project performs:

- Vector addition
- Vector subtraction
- Vector dot product
- Matrix addition
- Matrix multiplication
- Matrix determinant
- Matrix inverse
- Eigenvalues and eigenvectors

### 2. Probability Concepts

The project covers:

- Probability of successful sales
- Conditional probability using customer segments
- Bayes' theorem
- Binomial distribution
- Normal distribution
- Uniform distribution

The probability analysis uses customer segments such as Premium and Regular customers and their purchase probabilities.

### 3. Descriptive Statistics

The sales dataset is analyzed using:

- Mean
- Median
- Mode
- Range
- Variance
- Standard deviation
- Skewness
- Kurtosis

The results are interpreted to understand the central tendency, dispersion, and distribution shape of the sales data.

## 🔑 Key Skills Demonstrated

- Mathematical computing with Python
- Vector and matrix operations
- Probability reasoning
- Bayes' theorem
- Probability distributions
- Statistical analysis
- Data interpretation
- Numerical problem solving


## 🚀 How to Run

1. Download or clone this repository.
2. Open the `.ipynb` file using Jupyter Notebook, JupyterLab, Google Colab, or VS Code.
3. Install the required Python libraries if needed.
4. Run the notebook cells sequentially.
5. Review the calculated results and interpretations.

## 📈 Outcome

This project provides practical experience in applying mathematical and statistical concepts that are commonly used in Data Science, including linear algebra, probability, and descriptive statistics.
